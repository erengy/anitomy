# CLI

## Usage

```
anitomy [options...] <input>
```

## Options

```
--help             You are here
--stdin            Use standard input
--format=<format>  Set output format (`json` or `table`)
--pretty           Pretty print JSON
```

### Debugging

The following options are available for development purposes:

```
--debug            Print tokens instead of elements
--verbose          List all tokens, including brackets and delimiters
```
